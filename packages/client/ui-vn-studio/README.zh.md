# VN Studio

VN Studio 是本地 AI 辅助视觉小说制作工具。浏览器舞台由 React/Web API 实现，用于创作预览。同时配置 recoveredSystemDirectory 与 recoveredCompilerExecutable 后，最终游戏会实际编译并运行已复原的本地共通脚本和引擎，保留菜单、设置与存档系统，并应用作品自己的标题、指针和对白框。未配置时仍提供浏览器预览。

编辑器自带舞台、选项、标题、存读档、阅读记录、自动播放、快进、音频和设置。游戏进度与创作文档分开保存；重新开始不会丢弃尚未保存的编辑。原生存档仍保留在磁盘上，但不会导入浏览器进度。生成的作品标题、对白框和指针素材用于独立播放器；AI 面板共享作品标题图和实际制作数量。

只需配置 projectDirectory；previewDirectory 和旧编译器、字体字段仍可选以兼容旧配置。dev-tools/use-browser-player.mjs 可移除托管配置中的旧原生绑定，同时保留项目和账户设置。配置共通系统后，“运行游戏”会启动真正的游戏进程，“导出游戏”生成带 Game.exe 的 Windows ZIP 并打开文件位置；未配置时预览返回浏览器链接。导出不复制既有存档、创作历史或源代码工作目录。复原模板和原引擎仍是私有本地输入，不随服务源码发布。use-browser-player.mjs 是显式关闭此路径的选择，不应在需要共通系统时自动运行。

## Model Experience

默认启用的 vn-director 插件和随包技能会规划人物、关系、节奏和真实素材任务，随后写入完整场景。优先使用已登录的原生 Codex 图片能力，也可实际合成本地 WAV 音乐与音效。prepare_media 会为项目准备原创标题、透明指针和对白框。就绪检查依据已验证的素材文件、实际布置、场景可达性和计划节奏；保留既有素材、对白、选项和构图。必需素材未完成时作品仍为未完成。

ChatGPT 写作沿用账户与 Responses 集成；图片通过已安装 Codex 的公开 app-server 和其登录状态生成。应用不提取或发布凭据。可选 Images API 密钥独立配置。操作使用当前修订号、有限任务数和取消信号。智能体修改返回精简回执；显式读取及 UI 方法返回完整创作数据。

## 演出制作包（vn.16）

默认指导会规划情绪转折、参考图驱动的表情或姿势差分、事件 CG，以及选项的即时和后续反馈。新章节和用户要求的修改会自动采用该流程；既有章节不会被自动改写。详细示例随包位于 assets/skills/vn-director/references/direction.md。

lines[].visual 是完整画面快照，持续到下一个演出提示；未提供时继承此前快照或场景默认画面。支持 shot（wide、medium、close）、focus（当前人物槽位）、transition（cut、dissolve）和 cg（已入库的背景图片 ID，替代普通背景与人物）。每个新快照须包含希望继续的音乐。浏览器遵守减少动态效果设置；复原编译器会生成相应画面、原生转场和提示音，并记录提示与标志绑定。它不提供 Live2D 或任意动画时间轴。

选项支持有界布尔 when 和 effects。全部条件必须匹配，未设标志视为 false。结果保存在普通和快速存档中，重新开始时清空，不改写创作内容。原生标志使用专属具名共享属性，只在新游戏入口重置，读档则保留。没有这些新增字段的旧文档和浏览器存档仍可读取。这是布尔剧情记忆，不是数值好感度系统或阅读记录回滚。

图片任务可提供至多三个已入库的 referenceAssetIds。先生成基础人物图，再用返回的真实 ID 生成差分或事件 CG。参考图须通过完整性检查，并作为原生本地图片输入传给 Codex。可选的纯生成 Images API 适配器会明确拒绝参考图编辑请求。差分须布置到对应对白快照中；就绪检查识别场景与对白级布置。

## 限制与许可

浏览器预览可作为跨平台路径；尚未在真实 Mac 上测试。已配置的原生复原系统与导出目前为 Windows 路径。每个画面最多显示三个人物。用户已有故事和生成素材仍是用户数据。既有开源依赖保留其许可；独立播放器不代表整个上游应用成为专有或完全原创。历史逆向研究不授予原商业脚本、可执行文件或素材的商业分发权。
