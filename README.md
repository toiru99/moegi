# VN Studio — 로컬 AI 비주얼노벨 제작 도구

이 브랜치는 현재 작업한 VN Studio 서비스의 전체 소스입니다. 저장소의 기존 MOEGI 작업물과 통합하지 않았으며 `main`은 그대로 유지합니다.

비개발자가 AI에게 이야기를 요청하면 인물·관계·장면을 계획하고 대사, 그림, 음악·효과음과 작품별 타이틀·커서·대사창을 준비합니다. 편집기에는 장면 구성, 제작 계획, 소재 관리, 작품 정보를 보여주는 AI 채팅 패널이 있습니다. ChatGPT 연결과 로그인한 Codex의 이미지 기능을 사용합니다.

## 로컬 실행

외부 서버 배포 없이 이 컴퓨터에서 실행하고 브라우저의 `localhost`로 접속합니다. AI 호출에는 인터넷과 계정 연결이 필요합니다.

- Node.js 24.9 이상, pnpm 11.28.5를 사용합니다.
- 의존성 설치: `pnpm install`
- 빌드: `pnpm run build`
- 현재 Windows 개발 환경 실행: `./Start-VNStudio.ps1` (로컬 앱 3080, 로컬 플러그인 카탈로그 3091)
- 일반 로컬 웹 진입점: `pnpm dsh web --port 3080`

`Start-VNStudio.ps1`과 `dev-tools/configure-vn-profile.mjs`에는 현재 개발 PC의 로컬 도구·저장 위치가 들어 있습니다. 다른 PC에서는 경로를 환경에 맞게 설정해야 합니다. VN 플러그인 설치·설정은 [구성 설명](packages/client/ui-vn-studio/README.md)을 참고하세요.

## 자체 게임 플레이어

현재 기본 플레이어는 React와 Web API로 독립 구현한 브라우저 플레이어입니다. 게임 실행에 원작 Windows 실행 파일, 복원한 공통 스크립트, 원작 버튼/효과음 리소스나 Siglus 컴파일러를 호출하지 않습니다. 원작 시스템으로 플레이 버튼은 제거했으며, 게임 화면 안에서 대사·선택지·타이틀·저장·불러오기·설정·백로그·오토·스킵·음향을 처리합니다. 타이틀·대사창·커서는 작품에 대해 직접 생성한 그림을 사용합니다.

과거 원작 실행 관련 설정은 프로필 호환 때문에 읽을 수 있지만 실행 경로로 사용하지 않습니다. `vn_project preview`는 브라우저 프로젝트 링크/설명자를 반환하며 별도 게임 프로세스를 시작하지 않습니다. 기존 프로필은 `dev-tools/use-browser-player.mjs`로 사용하지 않는 엔진 연결 필드를 제거할 수 있습니다. 기존 작품, 그림, 음향, 계정과 네이티브 저장 폴더는 보존합니다.

## macOS 상태

자체 플레이어는 브라우저에서 실행하므로 원작 Windows 실행 파일에 대한 의존은 없습니다. 앱의 Node.js/계정 설정은 각 PC 환경에 맞게 준비해야 하며, 실제 검증 환경은 Windows입니다. macOS 실기기 검증 완료를 주장하지 않습니다.

## 현재 검증 범위

자체 플레이어 기능 테스트153개, 전체 빌드10개 검사, 최종 Client 번들과 실제 설치 후 브라우저 검증을 통과했습니다. 저장/불러오기, 선택지 이동, 설정 재접속 유지, 타이틀, 재시작, 오토/스킵/백로그, 모바일 설정창을 확인했습니다. 이전 원작 실행 경로에 대한 검증은 현재 플레이어의 검증과 구분합니다. 헬스시뮬 5장면·97개 대사와 기존 자산을 보존하며 실제 UI 그림 생성, 게임 형식 변환, 원작 타이틀 실행을 검증했습니다. 전체 상위 UI 회귀 검사에는 별도 실패 항목이 남아 있으며 전체 테스트 통과를 주장하지 않습니다. 정적 장면 구성, 장면별 최대 3인·선택지 5개를 지원합니다.
