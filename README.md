# VN Studio — 로컬 AI 비주얼노벨 제작 도구

이 브랜치는 현재 작업한 VN Studio 서비스의 전체 소스입니다. 저장소의 기존 MOEGI 작업물과 통합하지 않았으며 `main`은 그대로 유지합니다.

비개발자가 AI에게 이야기를 요청하면 인물·관계·장면을 계획하고 대사, 그림, 음악·효과음과 작품별 타이틀·커서·대사창을 준비합니다. 편집기에는 장면 구성, 제작 계획, 소재 관리, 작품 정보를 보여주는 AI 채팅 패널이 있습니다. ChatGPT 연결과 로그인한 Codex의 이미지 기능을 사용합니다.

## 로컬 실행

외부 서버 배포 없이 이 컴퓨터에서 실행하고 브라우저의 `localhost`로 접속합니다. AI 호출에는 인터넷과 계정 연결이 필요합니다.

- Node.js 24.9 이상, pnpm 11.28.5를 사용합니다.
- 의존성 설치: `pnpm install`
- 빌드: `pnpm run build`
- 현재 Windows 개발 환경 실행: `./Start-VNStudio.ps1` (로컬 앱 3080, 로컬 플러그인 카탈로그 3091)
- 일반 로컬 웹 진입점: `pnpm dsh web --port 3080`

`Start-VNStudio.ps1`과 `dev-tools/configure-vn-profile.mjs`에는 현재 개발 PC의 로컬 도구·저장 위치가 들어 있습니다. 다른 PC에서는 경로를 환경에 맞게 설정해야 합니다. VN 플러그인 설치·설정은 [구성 설명](packages/client/ui-vn-studio/README.md)을 참고하세요.

## 원작 공통 시스템

한국어·일본어용 원작 공통 스크립트·메뉴·선택지·저장/불러오기·설정과 원작 엔진을 개인 로컬 템플릿으로 연결합니다. 원작 게임 실행 파일, 상업용 그림·음향, 사용자 작품, 세이브, 로그인 정보와 API 키는 이 저장소에 포함하지 않습니다. 작품별 새 타이틀·커서·대사창은 기존 공통 UI의 그림 슬롯에 적용합니다.

개인 템플릿과 호환 컴파일러를 연결하려면 `recoveredSystemDirectory`, `recoveredCompilerExecutable`을 설정합니다. 연결된 복원 플레이어에서 컴파일에 실패할 경우 다른 플레이어로 자동 전환하지 않습니다.

## macOS 상태

웹 편집기와 AI 코드 기반은 macOS 실행 경로를 포함하지만 이 작업의 검증 환경은 Windows입니다. 복원한 원작 게임 플레이어는 Windows 실행 파일이며 macOS에서 동일하게 재생되는 상태까지 검증하거나 구현한 것은 아닙니다. 맥 완전 지원으로 표시하지 않습니다.

## 현재 검증 범위

VN Studio 기능 테스트 143개와 전체 빌드 10개 검사를 통과한 작업본입니다. 헬스시뮬 5장면·97개 대사와 기존 자산을 보존하며 실제 UI 그림 생성, 게임 형식 변환, 원작 타이틀 실행을 검증했습니다. 전체 상위 UI 회귀 검사에는 별도 실패 항목이 남아 있으며 전체 테스트 통과를 주장하지 않습니다. 정적 장면 구성, 장면별 최대 3인·선택지 5개를 지원합니다.
